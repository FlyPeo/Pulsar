# 来源与许可核查记录

本仓库最早公开提交 `b056cf2` 的
`include/pulsar/iomanager.hpp`、`noncopyable.hpp`、`thread.hpp`
仍出现 `__SYLAR_...` include guard。该事实不足以确定所用上游版本、复制范围
或适用许可证，也不能支持“所有代码从零原创”的表述。后续版本有实质性的
Boost.Context 迁移、调度器与栈复用改造、测试及本次可选网络/RPC 模块，
但这些改动不消除早期代码的来源核查义务。

当前 Pulsar 仓库没有 `LICENSE` 文件。发布前需要逐文件比对早期代码和
可疑上游版本，确认版权所有者、许可证文本、保留声明和分发条件，再确定
本仓库统一或分文件的许可方式。本次只在本地隔离 checkout 中实施和验证，
未创建发布包，也未将未核清的代码宣称为完全独立原创。
